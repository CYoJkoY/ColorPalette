# 商业化接入说明

ColorPalette 的商业化采用两条独立路径：付费订阅与激励广告兑换临时 Pro 权益。

## 激励广告

生产环境请在微信公众平台创建激励广告位，并将广告位 ID 配置到运行时配置中。只有激励视频完成后的 `isEnded` 成功回调才能发放权益。

推荐权益：一次完整广告 = 24 小时 Pro。建议增加每日兑换上限，避免权益系统被异常调用消耗。

客户端可以负责展示广告，但权益发放最好通过可信服务端或经过签名/校验的业务流程完成。不要因为 `show()` 成功就发放权益。

## 月卡 / 年卡

建议首测价格：

- 月卡：¥3.9 / 30 天
- 年卡：¥19.9 / 365 天

客户端只负责发起购买流程和展示状态。订单创建、支付结果校验、重复回调幂等、退款与权益到账应由服务端完成。

建议服务端订单状态：`created` → `paid` → `fulfilled`，并使用微信侧订单号建立唯一约束。

## 云同步

Pro 收藏同步建议以微信用户身份建立服务端数据记录。服务端只保存必要的色卡数据，不保存原始图片，除非产品明确需要云端图片历史。

## 配置原则

禁止将 AppID 之外的敏感生产凭据提交到 Git。广告位 ID、商户密钥、API 密钥、用户隐私数据等应使用微信云开发环境变量或独立后端的安全配置。
